1 ERWYNA (0:12) Hi, I'm Erwyna and this is Taabish. Taabish covers Task 1: rotating big images on a GPU with CUDA. I cover Task 2: the ethics of scaling HPC for AI, then our limits.
2 TAABISH (0:20) An 8K frame has 33 million pixels, each output pixel depends only on the input, so data parallel. Inverse mapping: each thread owns one output pixel and applies R transpose to find its source, so no holes and no write races.
3 TAABISH (0:35) cudaMalloc reserves both buffers in GDDR6. Host to device: the GPU's DMA copy engine pulls bytes over PCIe. From pageable memory the driver first copies into a pinned staging buffer. cudaMallocHost gives page-locked memory so DMA reads it directly and async copies can overlap. Kernel works only in GDDR6, then device to host brings the result back. PCIe is the narrow pipe: pinned 12.3 GB/s against 320 inside the T4, pageable 2.7x slower.
4 TAABISH (0:25) Host allocates, copies, picks launch configuration, launches asynchronously, syncs, checks errors. Device runs thousands of threads SIMT style. Block 16x16 = 256 threads = 8 warps of 32. For 8K the grid is 480x270 blocks, one thread per pixel.
5 TAABISH (0:10) One picture of the layout: grid of blocks, each 16x16 threads, one thread per output pixel.
6 TAABISH (0:20) Kernel from our submission. x and y from blockIdx*blockDim+threadIdx, guard drops threads past the edge, R transpose finds the source pixel so every output pixel has one writer. Launch rounds the grid up, 480x270 blocks for 8K, error checked straight after because launches are asynchronous. [slide shows two EMPTY screenshot frames Erwyna fills with her own screenshots of rotate_cuda.cu lines 145-158 and 360-383]
7 TAABISH (0:40) One variant per CUDA feature. 2D grid beat 1D, 1.55 vs 2.96 ms (1D pays a divide and modulo per thread). Even against all Colab CPU cores the GPU wins, but a 14-thread laptop beats it end to end. Against one CPU core kernel 328x, end to end 29.6x because copies are 91% of the time, so Amdahl caps at 32.6. At 128 GB/s, 40% of peak, kernel is memory bound.
8 TAABISH (continues 7) Six variants: 1D grid, 2D 16x16, bilinear, pageable, streams, texture. Amdahl bound 509.3/(8.06+7.58)=32.6x so 29.6 is 91% of it. Against all Colab CPU cores T4 still 27x end to end; a 14-thread laptop takes 14.5 ms, faster than the T4's 17.2.
9 TAABISH (0:30) GPUDirect Storage lets NVMe DMA straight into GPU memory, CPU keeps only the control path through cuFile, bounce buffer goes away. For the company: yes, but only for the bulk pipeline, and only if frames are raw or decoded on the GPU with nvJPEG. Not one photo, not JPEGs decoded on the CPU, not images already in RAM.
10 ERWYNA (0:15) IEA: 415 TWh in 2024, about 1,200 by 2035, GPU servers drive the growth.
11 ERWYNA (0:20) Frontier and LUMI use the same MI250X nodes, GFLOPS/W almost equal. LUMI runs on hydropower and heats part of a Finnish town. Carbon cost of a FLOP depends on the grid, not only the chip.
12 ERWYNA (0:22) Johor 10 MW to over a gigawatt in about three years; data centres could use almost a third of Peninsular electricity by 2035 on a grid 79% fossil. Kajaani is the opposite. Myth check: AI does not emit more CO2 than aviation today, that is a 2030 projection. (If asked: Johor stopped approving new water-hungry Tier 1 and 2 sites.)
13 ERWYNA (0:35) Where the GPUs are decides which country's law covers the data. Data-parallel training swaps gradients, gradients can leak training data, so residency becomes a scheduling rule. Security is dual-use: same chips train a hospital or a military model; US limits exports, since July 2025 Malaysia needs a permit. Fairness: Malay is under 0.1% of web text.
14 ERWYNA (0:25) Over 90% of notable 2025 models came from industry. Frontier compute grows about 5x a year, best academic model about 3,000x lower. Most academics 1 to 8 GPUs (NCI Gadi 776 GPUs, demand about 3x allocation). If only companies train frontier models, only companies can audit them.
15 ERWYNA (0:35) UNESCO, OECD, AIGE give values, no number to report. EU closer: AI Act flags models above 10^25 FLOP, big sites report PUE. So SCALE: each step is a Slurm setting and a reported number. Size right; Carbon-aware (up to 19% less CO2 for jobs that can wait); Account every joule; Lawful local data; Equitable access.
16 ERWYNA (0:28) Task 1 limits: one-core CPU baseline on shared Colab VM, speed-ups belong to that setup, no GDS test. Next: nvJPEG, GDS, streams on a GDS server. Takeaways: rotation is memory bound, PCIe sets the ceiling; cost of a FLOP depends on where and for whom it runs.
